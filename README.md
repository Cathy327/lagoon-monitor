# Lagoon Water Quality Monitor

A remote sensing dashboard for monitoring algal bloom indicators in a lagoon near Ballarat, Victoria, using Sentinel-2 satellite imagery from Google Earth Engine.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Cathy327/lagoon-monitor/blob/main/update_data.ipynb)

## Overview

This tool provides EPA VIC with a local web-based dashboard to visualise two water quality indices derived from Sentinel-2 imagery:

- **FAI (Floating Algae Index)** — detects potential floating algae signals on the water surface, useful for identifying short-term bloom spikes.
- **NDCI (Normalised Difference Chlorophyll Index)** — estimates chlorophyll-a concentration as a proxy for algal biomass.

The dashboard displays satellite imagery from January 2024 to present, with automated incremental updates via Google Colab.

## Features

- Side-by-side FAI and NDCI raster maps overlaid on a real basemap
- Date selector to browse all available satellite imagery
- Three-year same-period comparison with configurable date window
- Full time series trend charts with standard deviation error bands
- Manual algal bloom event logging with severity levels
- Automated data updates via Google Colab (no local Python installation required)

## Quick Start

### First-Time Setup

1. Receive the initial `data/` folder from the project team (USB or zip file).
2. Clone or download this repository.
3. Place the `data/` folder in the same directory as `index.html`.
4. Open `index.html` in a web browser.

### Updating Data

1. Click the **Open in Colab** button above.
2. Log in with the provided Google account.
3. Click **Runtime → Run all**.
4. Wait for processing to complete (incremental updates take 2–5 minutes).
5. Download the generated zip file.
6. Extract and replace the `data/` folder in your dashboard directory.
7. Refresh `index.html`.

See [docs/user_guide.md](docs/user_guide.md) for detailed instructions with screenshots.

## Data Sources

- **Satellite imagery**: Copernicus Sentinel-2 Surface Reflectance Harmonized
- **Spatial resolution**: 10 metres
- **Cloud filter**: < 30% scene cloud cover
- **Temporal coverage**: January 2024 – present
- **Study area**: Lagoon boundary digitised in QGIS, stored as a GEE asset
